## 1.6.1：点击查看后的等待修复

本节取代上文关于详情仍执行完整准备链、约需一分钟的限制说明。

- 根因：1.6.0 仅首页使用轻量结果索引，详情仍调用完整准备链读取器；此外每次请求都会重复进行大型 v3 评分 schema 校验。

- 校验缓存按报告与 schema 的实际内容键控，不依赖文件名或修改时间；返回副本，避免调用方修改缓存。报告、schema 或自哈希变化均重新验证。
- 点击查看立即返回读取状态页，内容通过同源请求加载；请求错误显示可重试提示。
