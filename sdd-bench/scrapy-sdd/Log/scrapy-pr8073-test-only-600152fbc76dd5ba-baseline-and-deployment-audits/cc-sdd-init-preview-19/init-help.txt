Usage: cc-sdd [options]

Options:
  --agent <claude-code|claude-code-agent|claude-code-skills|codex|codex-skills|cursor|cursor-skills|github-copilot|github-copilot-skills|gemini-cli|gemini-cli-skills|windsurf|windsurf-skills|qwen-code|opencode|opencode-agent|opencode-skills|antigravity-skills>  Select agent
  --claude-code | --claude | --claude-code-agent | --claude-agent | --claude-code-skills | --claude-skills | --codex | --codex-cli | --codex-skills | --cursor | --cursor-skills | --copilot | --github-copilot | --copilot-skills | --github-copilot-skills | --gemini-cli | --gemini | --gemini-cli-skills | --gemini-skills | --windsurf | --windsurf-skills | --qwen-code | --qwen | --opencode | --opencode-agent | --opencode-skills | --antigravity-skills | --antigravity  Agent alias flags
  --lang <ja|en|zh-TW|zh|es|pt|de|fr|ru|it|ko|ar|el>  Language
  --os <auto|mac|windows|linux>               Target OS (auto uses runtime)
  --kiro-dir <path>                           Kiro root dir (default .kiro)
  --overwrite <prompt|skip|force>             Overwrite policy (default: prompt)
                                              prompt: ask for each file
                                              skip: never overwrite
                                              force: always overwrite
  --backup[=<dir>]                            Enable backup, optional dir
  --profile <full|minimal>                    Select template profile (default: full)
  --manifest <path>                           Manifest JSON path for planning
  --dry-run                                   Print plan only
  --yes, -y                                   Skip prompts (prompt -> force)
  -h, --help                                  Show help
  -v, --version                               Show version

Note: In non-TTY environments, prompt mode falls back to skip.
