## 如何解释“命中”

Top-200 在 80/96 个 PR 中至少找到一个目标，但只有 47/96 个 PR 找全了目标。总体命中 392/1,145，仍有 753 个参考目标排在 200 名以后。

宏平均让每个 PR 权重相同，总体召回让每个目标权重相同。目标数最多的 10 个 PR 含 808 个目标，占全部目标 70.57%；Top-200 仅命中其中 208 个，召回率 25.74%。这是两种汇总值差异的主要来源。
