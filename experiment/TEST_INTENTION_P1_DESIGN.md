# P1字段、阅读与离线比较契约

版本v1，2026-11-03。先固定字段与比较方式，再实现TI-08→TI-06→TI-07；本阶段不调用模型、不读取68个独立测试PR的标签，不更改旧表示和预测。

## 已有字段与接入范围

22个base共53,249条版本化记录，其中6,274条STATIC_FALLBACK。现有静态字段为assertions、assignments、calls、conditions、mock、parameters；它们的非空记录数分别为47,494、45,203、53,073、4,964、3,652、16,730。直接依赖边和源码位置也已保存。

TI-08只投影这些记录，不重新解析AST。没有独立保存的完整导入表、资源生命周期和完整继承图列为TI-09缺口。配置键可通过已保存表达式查询，不假称已有完整配置键分析。owner只从既有qualified ID拆出，不推断运行时类归属。

| 检索域 | 来源与指针 | 性质／缺失 |
| --- | --- | --- |
| identity、path、owner | tests.id/path与限定名的确定性拆分 | 身份事实；模块函数owner为空 |
| semantic.* | intention中的summary、inputs、operations、environment_mock、scenarios、uncertainties | 模型解释；回退为缺失，不补造摘要 |
| facts.* | 既有六类静态记录的字符串值 | 静态事实／候选；line只作来源，不参与词匹配；status等管理字段不作相关性依据 |
| dependencies | 已保存、当前测试出发的depth=1依赖边 | 静态候选；不展开邻居或增加边 |

字段由JSON指针引用原记录，保留原文和来源行号；索引使用Unicode casefold，原文不改写。不把字段名、文件校验和或JSON管理键当作正文。缺失字段可查询其覆盖状态，测试仍通过身份独立可查。

## 阅读与分页

search返回短目标、身份／状态、命中字段、原文片段及回查指针；show等原视图保留。match按指针回查，场景命中返回完整条件／动作／预期关联，静态命中返回对应事实。摘要省略明确标记，完整长记录仍分片。

多次--query形成字面子串子句，--mode or／and明确组合；单个子句不隐式拆成多个检索条件。空查询浏览全部测试。可显式选择字段，但默认全库全字段，不用文件／邻居当硬门槛。

新search分页使用游标，绑定实际索引与原证据文件哈希、reader／排序版本、查询、字段、排序和页参数；改变后拒绝旧游标。固定并列ID顺序。匹配测试数、分页单元数、当前返回单元与完整测试数分别报告，分片不冒充多个测试。原v2包的旧reader与行为保持不变。

## 排序候选（先固定，不按结果调参）

默认比较候选为field-bm25-v1，另保留tfidf与ID顺序作比较。两种词法方法使用同样的字段、匹配集合和短结果。字段权重：identity=8、path/owner=5、calls/mock=4、summary/assertions=3、assignments/dependencies=2，其余=1。精确字段等于完整子句的加分使用同一字段权重；词权重随文档频率降低，弱泛词不能获得与稀有符号相同的权重。

field-bm25-v1按字段分别用k1=1.2、b=0.75做长度归一，再加权求和，不宣称是标准BM25F实现。tfidf用相同字段的对数词频与文档频率，按向量长度归一。两种方法都保持确定性，分数相同按ID排序。即使某方案在开发结果较好，本阶段不根据标签继续调权重。

## 固定查询与比较

主要查询仅从原30PR的公开title/body产生：按出现顺序提取标识符／单词，保留具体符号，排除预先固定的普通英语停用词、纯数字及URL，最多16个不同子句，OR组合；不看目标方法名选词。原公开文本和查询字节在执行比较前封存。

每个查询固定单页6,000 UTF-8输出字节、最多25个单元；这是检索阅读预算，不是token或最终Detect预算。比较五组：

| 组 | 候选匹配字段 | 展示 | 排序 |
| --- | --- | --- | --- |
| L | 原v2的身份＋完整语义JSON匹配 | 原卡片 | ID |
| T | P1已有事实投影 | 原卡片 | ID |
| S | 同T | 短结果 | ID |
| R | 同T | 短结果 | field-bm25-v1 |
| F | 同T | 短结果 | tfidf |

先生成并封存全部候选结果、输出和哈希，再在宿主机读取现有30PR的封存标签。固定身份和分母，报告完整可见候选的Recall@6000B、首个目标位置／MRR@预算、候选精度、匹配集合覆盖率、展示数量及字节。长记录只有分片完整回收后才计为完整可见候选；同时公开分片限制。

回查成本不由gold决定：对每查询的第一条结果，测量其show视图所需字节及额外调用数；不把这个数字当作Agent实际token或完整推理成本。另验证全部返回命中片段／指针与原字段一致、跨页不重不漏、变更后旧游标拒绝。

这些是开发集离线检索结果，不是三种SDD的新定位分数，也不证明Agent会选择这些候选。30PR曾用于诊断；本次不读取独立测试集标签。未改善和下降同样保留。
