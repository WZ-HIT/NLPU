默认短卡片、语义内容、静态／维护数据库、搜索索引和关系与阶段 A 相同；本阶段改变的是按需阅读入口与后续共同判断提示。A 的 v5、原 P2 和历史执行根保持原样。后续三组比较使用同一共同判断及过程记录规则，不能把提示收益单独归因于语义意图。

## 来源与工具验收

- 核查全部 53,249 条测试所映射的 **1,398,318 个版本化事实位置**。这些是已有事实的视图，不是新生成了这么多条语义。
- 每个 base 对 11 类敏感点选取公开来源样例，在 6,000／12,000 字节限制下检查展开、回查、分页还原与默认卡片，共 **1,452 次读取器调用**。
- 最终发布修正了读取器启动时可能写入 Python 字节码缓存的问题；仅入口脚本变化，其余数据和映射文件与已验收版本逐字节一致。22 个最终包再通过实际宿主校验器及 66 次无 `-B` 的启动检查，未增加包内缓存文件。
- **48 项相关自动检查通过**：来源关联、源码变化拒绝、短输出限制、真实入口不写缓存、记录格式与身份、重复／上限、中断原子替换、目录越界、诊断状态，以及原输出契约回归。
- 独立从封存 ID 重算 **1,146 条查询×版本记录**，结果一致；30 个旧材料对照完整复现 P2 已封存排名与首屏，确认对照未漂移。

原始验收文件见 [来源核查](/data2/wangzuohit/NLPU-experiments/test-intention/stage-b-20261109-v1/source-verification.json)、[最终发布核查](/data2/wangzuohit/NLPU-experiments/test-intention/stage-b-20261109-v1/publication-v2/verification.json) 和 [独立汇总](/data2/wangzuohit/NLPU-experiments/test-intention/stage-b-20261109-v1/stage-summary.json)。

## 固定公开查询：全池改善，首屏下降

沿用此前冻结的 30 条 title/body 查询，29 个 PR 有正例。对照是旧 P2 材料，新版是阶段 A 补齐语义后、增加 B 阅读入口的材料；算法、权重和并列规则不变。每页最多 6,000 字节、25 项，字节限制会使实际返回少于 25 项。

| 指标 | 旧 P2 | 新版 | 差值 |
| --- | ---: | ---: | ---: |
| 首屏宏召回 | 38.79% | **36.49%** | −2.30 个百分点 |
| 首屏微召回 | 6.93% | **6.37%** | −0.55 个百分点 |
| 全匹配集合宏召回 | 83.72% | **85.56%** | ＋1.84 个百分点 |
| 首屏命中目标条目 | 25 | **23** | −2 |
| 首屏平均完整候选数 | 10.17 | **9.83** | −0.33 |

宏召回先对各有正例 PR 求召回再平均；微召回把所有目标合并。PR7808 有大量目标，因此两个数差异很大。全匹配集合召回表示目标可以通过完整翻页到达，不能当作首屏结果或最终模型预测。

只有三个 PR 的首屏／全池命中数发生变化：

| PR | 首屏命中：旧→新 | 全池命中：旧→新 | 观察 |
| --- | ---: | ---: | --- |
| 7702 | 0→0 | 2→3 | 多了一个可匹配目标，仍未进入首屏 |
| 7918 | 1→1 | 1→2 | 多了一个可匹配目标，首屏命中不变 |
| 8002 | 2→0 | 3→3 | 两个目标从第 8／9 位后移至第 10／11 位；首屏可容纳项数从 10 降到 9 |

因此，补齐语义确实增加了一些命中，但也改变词频、排序竞争和返回长度。**本轮不能宣称新增语义已经优化了定位指标。** 没有据此修改固定查询或按标签调整权重；后续若改排序，需要另作设计修订。

全部 30 PR 差值见 [fixed-query-differences.json](/data2/wangzuohit/NLPU-experiments/test-intention/stage-b-20261109-v1/fixed-query-differences.json)。

## 历史实际查询：单独保留事后诊断

从 90 份旧执行日志恢复 545 次合法的字面量搜索，按 PR、SDD 和选项去重后为 **543 条**。另有 **58 个无法合法回放的片段**，其中 42 个使用未知检索字段；没有把它们自动改成另一个查询。其他脚本、自定义搜索或动态表达式不保证被完整恢复，不能把本表当作全部搜索活动。

历史查询回放同样从首屏、以 6,000 字节／25 项预算开始，不重现原日志所有分页与输出选项。

| 指标，按恢复查询平均 | 旧 P2 | 新版 |
| --- | ---: | ---: |
| 首屏宏召回 | 21.38% | 21.98% |
| 全池宏召回 | 28.72% | 30.74% |
| 首屏平均完整候选数 | 4.95 | 4.82 |

这些查询是在不同调查目的下产生的，有的只寻找一个局部子集，因此平均召回低不等于整轮任务召回低；查询多的 PR 权重更大，也不是 543 个独立任务。它们只用于检查材料在实际词语下的可达性。

两类合计完成 **1,146 次回放**，核查 **140,611 个短结果命中引用及分页单位**，顺序无重复、无漏项，命中片段可回到原字段。全部输出字节、翻页次数和首项证据回查成本保留在各查询的排名文件中；不据字节推算模型 token 或费用。

## 目标上的覆盖与阶段诊断

361 个历史目标条目中，新版有 **356 条语义意图、5 条静态回退**，语义覆盖率 98.61%；旧版为 165 条语义。剩余 5 条全部在 PR7808。该 PR 从原先 175 个目标中仅 3 个有语义，变成 **170 个有语义**。

但固定公开查询下，361 个目标仍有：

| 位置 | 目标条目 |
| --- | ---: |
| 首屏完整可见 | 23 |
| 在完整匹配集合中，但需继续翻页 | 160 |
| 该固定查询未匹配 | 178 |

其中 PR7808 的 175 个目标有 162 个未匹配、13 个在后续页。**有意图与查询能命中是不同关卡**；本表只评价冻结查询，不能据此断定 Agent 自主重写查询也找不到。

历史实际输出另导出“名字出现／完整结果可见／源码行返回／未知”证据，与最终选择、失败状态及本轮检索结果对应。旧运行没有 TI-21 记录，排除理由与方法编辑理由保持未知；返回过源码不代表读懂关键条件。四个例子的人工日志回顾单列，不自动填充所有候选的归因。

| 案例 | 本轮核实的诊断边界 |
